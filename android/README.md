# Android build (Capacitor)

This directory is the native Android shell for the Cat Facts app, generated by
Capacitor (`npx cap add android`). It wraps the web app (built into `dist/`)
inside a WebView and produces an APK.

## Prerequisites

- Node.js (the project uses the lockfile; `npm install` from the repo root)
- Java 21 (JDK)
- Android SDK with:
  - `platforms;android-35` (or newer)
  - `build-tools;35.0.0` (or newer)
  - `platform-tools`
- `ANDROID_HOME` pointing at the SDK and `JAVA_HOME` pointing at JDK 21.

If you opened this in Android Studio it will offer to download the SDK for you.

## Build the APK (debug)

From the repo root:

```bash
npm install
npm run build                 # produces dist/
cd android
./gradlew -q app:assembleDebug
```

The APK lands at:

```
android/app/build/outputs/apk/debug/app-debug.apk
```

Package: `com.afkark.catfacts`
Label: "Cat Facts"
Version: 1.0 (code 1)

## Sync web assets after changing the React app

```bash
npm run build
npx cap sync android
```

Then rebuild the APK with `./gradlew app:assembleDebug`.

## Run on a device / emulator

With a device connected (USB debugging on) or an emulator running:

```bash
cd android
./gradlew installDebug
```

Or use `npx cap run android` from the repo root (it builds + deploys).

## Release build / signing

This repo ships a debug build by default. For a release build you need to
add a signing config to `app/build.gradle` and run `./gradlew app:assembleRelease`.
Debug APKs are signed with a debug key and are fine for side-loading/testing.

## Files intentionally not committed

- `android/.gradle/` (Gradle cache)
- `android/app/build/` (build outputs, including the APK)
- `android/local.properties` (your SDK path)
- `capacitor.config.json` (regenerated per machine by `npx cap sync`)
- `android/app/src/main/assets/public` (copied web assets)
- `android/app/src/main/assets/capacitor.config.json`
- `android/app/src/main/assets/capacitor.plugins.json`

A fresh checkout can regenerate all of the above from the source in this
directory plus `npm install` + `npm run build` + `npx cap sync android` from
the repo root.
